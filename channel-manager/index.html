A private tool by IcarusByEthan

Uploads and analytics for IcarusByEthan.

Icarus Channel Manager is a private tool operated by Ethan Oaks for the IcarusByEthan Etsy business. It uses Google OAuth and YouTube API Services for owner-authorized video uploads and channel analytics.

Private operator access. This website explains the tool and its policies; it does not offer public sign-ups. The private connection has been tested for channel access, analytics, token refresh, and an explicitly private upload. The app has not been verified or endorsed by Google.

A narrow purpose

This owner-operated tool is intended for direct YouTube uploads and channel reporting—not for public sign-ups, customers, or use as a SaaS or mobile app. Its planned access is limited to the owner's selected channel and authorized tasks. Google authorization may grant access more broadly than one channel; this site does not claim the OAuth token is technically restricted to a single channel.

It is not affiliated with or endorsed by Google or YouTube.
